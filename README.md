# INFRA MCP

AI infrastructure intelligence for agents, operators, and infrastructure developers.

## Overview

INFRA MCP is an experimental MCP server designed to make infrastructure intelligence accessible to AI agents.

The initial project focuses on structured information about data centers and digital infrastructure.

## Problem

Information about physical infrastructure is often distributed across public records, regulatory documents, company announcements, utility information, and other sources.

This makes infrastructure research difficult to search, combine, and use programmatically.

## MVP

The first version of INFRA MCP will allow an AI agent to query a structured dataset containing information about data centers and infrastructure projects.

Example questions:

- What data centers are being developed in Georgia?
- Which projects are located in a particular county?
- What is the reported capacity of a project?
- What is the source of the information?
- When was the information last verified?
